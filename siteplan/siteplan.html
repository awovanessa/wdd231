PortFolio Hub: Site Plan

A blueprint for my individual website project: a portfolio that shows what I build and how to reach me.

Site Name

PortFolio Hub

The name signals a central place for my portfolio projects as a student developer.

Site Purpose

To showcase my web-development projects and skills so visitors can quickly see what I build, how I build it, and how to contact me for collaborations or internships.

Scenarios

Questions a visitor from the target audience (recruiters, hiring managers, and potential collaborators) will ask:

  1. What projects has this person built, and what technologies did they use?
  2. How can I contact them for a project or internship opportunity?

Color Scheme

Two theme colors and where each is used
Color Hex Where it is used
Navy #0B3D6C Header background, primary buttons, section headings, and link hover.
Teal #1ABC9C Accent highlights (technology tags), button hover state, and small decorative borders and underlines.

Text is black on white backgrounds, and white on navy. Navy text is used on teal, which keeps the contrast readable.

Primary button (navy) HTML5 CSS3 JavaScript

Typography

Poppins: headings

Used for all H1, H2 and H3 headings. The headings on this page use it.

Inter: body text

Used for paragraphs, lists and general content. This paragraph is set in Inter.

Fira Code: code and technology tags

Used for code snippets and technology tags such as HTML5 CSS3 React.

Wireframe

Home page layouts in black and white. On small screens the projects grid is one column; on wider screens it becomes three columns.
